# Uibrium Roadmap

> This roadmap is maintained by Aaryan Gupta ([@aryanony](https://github.com/aryanony)).
> Want to help? Pick an item and open a PR! Check [Good First Issues](https://github.com/aryanony/uibrium/labels/good%20first%20issue) for beginner-friendly tasks.

---

## v1.1 — Component Expansion

- [ ] 🔔 Toast / Notification system
- [ ] 📊 Progress Bar component
- [ ] 💀 Skeleton loader
- [ ] 📅 DatePicker component
- [ ] 🔍 Combobox / Autocomplete component
- [ ] 🎨 Color Picker

## v1.2 — Quality & Testing

- [ ] ✅ Unit tests for all existing components (Vitest)
- [ ] 🎭 Set up Chromatic visual regression testing
- [ ] ♿ Automated accessibility testing (axe-core)
- [ ] 📖 Complete JSDoc coverage on all component props

## v1.3 — Developer Experience

- [ ] 📦 CLI tool for scaffolding new components
- [ ] 🪝 Utility hooks library (`useMediaQuery`, `useDebounce`, etc.)
- [ ] 🌐 i18n / RTL support
- [ ] 📱 Responsive variants for all components

## v2.0 — Future Vision

- [ ] 🧩 Headless mode (unstyled primitives)
- [ ] ⚡ React Server Components compatibility
- [ ] 🎨 Theme builder UI (visual token editor)
- [ ] 📊 Bundle size dashboard (automated tracking)

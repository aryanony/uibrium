# Contributing to UiBrium

First off, thank you for considering contributing to UiBrium! It's people like you that make UiBrium such a great tool for the tech industry.

## Our Philosophy

UiBrium is built on the principles of **Deterministic Symmetry** and **Emotional resonance**. We believe that UI components should not only be functional but also deliver a premium, unforgettable experience.

## How Can I Contribute?

### Reporting Bugs

- Use the GitHub issue tracker to report bugs.
- Describe the bug in detail and provide steps to reproduce.
- Include information about your environment (browser, OS, library version).

### Suggesting Enhancements

- Enhancements are welcome! Please open an issue to discuss your idea first.
- We prioritize features that align with our "Premium" and "Lightweight" goals.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. Install dependencies: `pnpm install`.
3. If you've added code that should be tested, add tests.
4. If you've changed APIs, update the documentation.
5. Ensure the build passes: `pnpm build`.
6. Submit a pull request.

## Style Guide

- Use TypeScript for all components.
- Follow the established HSL color palette and Tailwind styling patterns.
- Keep animations smooth and meaningful using Framer Motion.
- Ensure accessibility (ARIA labels, keyboard navigation).
